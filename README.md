# 🏡 Dashboard BUMDes Desa Badran

Aplikasi berbasis web interaktif untuk mendukung operasional dan digitalisasi Badan Usaha Milik Desa (BUMDes) di Desa Badran, Temanggung. Proyek ini dikembangkan sebagai bagian dari program pengabdian masyarakat **KKN GIAT 13 Universitas Negeri Semarang (UNNES)**.

## 🌟 Fitur Utama
*   **Profil BUMDes:** Informasi umum terkait struktur organisasi dan unit usaha BUMDes.
*   **Visualisasi Data:** Dashboard interaktif untuk memantau data operasional dan potensi desa.
*   **Antarmuka Responsif:** Dibangun menggunakan Streamlit sehingga ringan, cepat, dan mudah diakses melalui berbagai perangkat.

## 🛠️ Teknologi yang Digunakan
*   **Bahasa Pemrograman:** Python 3.x
*   **Framework Web:** [Streamlit](https://streamlit.io/)
*   **Library Pendukung:** Terdaftar di `requirements.txt`
